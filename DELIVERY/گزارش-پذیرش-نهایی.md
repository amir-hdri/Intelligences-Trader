## ۱. خلاصه اجرایی

این پروژه (اکوسیستم معاملات الگوریتمی بورس کالای ایران، سه سرویس: فرانت‌اند React + بک‌اند تحلیل ML + پراکسی داده) با **ممیزی مستقل چهاربعدی** (بک‌اند ۳۴ یافته، فرانت‌اند ۳۲، زیرساخت ۳۷، ML/داده ۱۹ — مجموع ۱۲۲ یافته) تحلیل شد و مهم‌ترین شکاف‌ها رفع گردید.

**مهم‌ترین شکاف‌ها و رفع آن‌ها:**
1. **نبود پایگاه‌داده** (بزرگ‌ترین شکاف) → لایه DB واقعی با `node:sqlite` + migration + seed + جدول‌های users/predictions/trades/audit_events/settings/market_snapshots اضافه شد.
2. **احراز هویت dummy** (بر اساس env) → register/login/refresh با `crypto.scrypt` (نمک‌دار، timing-safe) + JWT + middleware واقعی `requireAuth/requireAdmin`.
3. **جعل متریک** (`Math.max/min` در `/api/train`، `+0.05` در drift) → حذف شد؛ گزارش صادقانه.
4. **باگ `candles` تعریف‌نشده** (position-sizing همیشه fallback) → رفع شد.
5. **کرش بوت** (`pino-pretty` نصب‌نشده، `traceExporter` با نوع Winston) → رفع شد.
6. **زیرساخت شکسته** (secrets نبود، مسیر مدل ناسازگار، curl در alpine، k8s Secret تعریف‌نشده) → docker-compose/.dockerignore/.env.example/scripts/generate-secrets.sh/k8s-secret.yaml اصلاح شد.
7. **داده جعلی در فرانت** (`Math.random` برای نتیجه معامله) → ثبت واقعی سفارش در ledger.

## ۳. خلاصه تغییرات (رفع‌شده)

### بک‌اند (`robot trader/server/`)
| تغییر | جزئیات |
|---|---|
| **لایه DB** | `db/database.js`، `db/repositories.js`، `db/migrations/001_init.sql`، `auth/authService.js` (جدید) |
| **اتصال DB به سرور** | import + init در `index.js`؛ endpoint های register/login/refresh/me + predictions/trades/audit |
| **احراز هویت واقعی** | scrypt + JWT؛ middleware `requireAuth/requireAdmin/requireDb` |
| **رفع باگ candles** | `/api/tse/history/:symbolId` اکنون از `historyData` استفاده می‌کند |
| **حذف متریک جعلی** | `/api/train` مقادیر واقعی accuracy/sharpe/drawdown/calibration برمی‌گرداند |
| **رفع shadow-mode** | `analysis.action` → `analysis.prediction` |
| **رفع drift جعلی** | `modelManager.monitorDrift` فاکتور `+0.05` حذف شد |
| **رفع بازآموزی جعلی** | `triggerAutoRetrain` دیگر نسخه مدل را جعل نمی‌کند |
| **رفع predict batch** | `modelManager.predict` هر نمونه را batch=1 پردازش و shape را اعتبارسنجی می‌کند |
| **رفع HPO 500** | endpoint به `hpoEngine.optimize` متصل + clamp تعداد trials |
| **رفع کرش بوت** | `pinoLogger.js` fallback بدون pino-pretty؛ `logger.js` از `ConsoleSpanExporter` واقعی |
| **رفع MACD** | سیگنال MACD = EMA-9 واقعی خط MACD (نه `value*0.9`) |
| **رفع پورت سخت‌کد** | `process.env.PORT || 3000` |
| **امنیت seed** | رمز admin تصادفی وقتی `ADMIN_PASSWORD` تنظیم نشده (نه `admin123`) |

### فرانت‌اند (`robot trader/src/`)
| تغییر | جزئیات |
|---|---|
| **رفع env** | `process.env` → دسترسی صحیح + `define` در `vite.config.ts` (VITE_BACKEND_URL/PROXY_URL/WS_URL) |
| **رفع routing** | `/api/tse`، `/api/analyze`، `/api/news`، `/api/train` → `API_BASE_URL` (3000)؛ orderbook → proxy (3001) |
| **رفع نتیجه جعلی معامله** | `Math.random()` حذف؛ ثبت سفارش در `/api/trades` |
| **کلاینت API + auth** | `services/api.ts` (login/token/predictions/trades) |
| **فرم ورود** | تب Settings → Account Authentication |
| **دکمه مرده** | «Execute Multi-Leg Spread» غیرفعال + توضیح (نیاز به API کارگزاری) |

### زیرساخت / Ops

## ۵. تحلیل شکاف — موارد باز (با دلیل روشن)

موارد زیر **عمداً باز مانده** و نیازمند داده/تصمیم ذی‌نفع هستند (خارج از محدوده اجرای بدون داده واقعی):

| # | شدت | مورد | دلیل بازماندن |
|---|---|---|---|
| 1 | HIGH | **دو مدل ONNX ناسازگار** (پایتونی `[batch,30,5]` با ۲ خروجی در برابر نودی `[batch,30,10]` با خروجی `[1,3]`) | نیاز به «قرارداد مدل» واحد + داده آموزشی واقعی بازار؛ بازسازی مدل نودی بدون داده واقعی، جعل دیگری است. |
| 2 | HIGH | **ناسازگاری فضای اکشن PPO** (جهت گسسته مدل در برابر دیکد پیوسته محیط) | بخشی از همان قرارداد مدل؛ رفع بدون داده آموزشی + تایید معنا ندارد. |
| 3 | HIGH | **استپ deploy در CI/CD وصل نیست** (تصاویر `ghcr.io` ساخته می‌شوند اما k8s را به‌روز نمی‌کنند) | نیاز به انتخاب ابزار استقرار (ArgoCD/kustomize) و اعتبارنامه خوشه — خارج از محدوده (بدون دسترسی). |
| 4 | MEDIUM | **EKS 1.28 منسوخ + terraform ناقص** (بدون ECR/RDS/IRSA/remote-state) | انتخاب زیرساخت ابری نهایی + اعتبارنامه — خارج از محدوده. |
| 5 | MEDIUM | **منابع داده واقعی TSETMC** — اکثر endpointها fallback شبیه‌سازی دارند | اتصال پایدار به CDN واقعی در محیط sandbox ممکن نیست؛ داده شبیه‌سازی با برچسب لازم است. |
| 6 | LOW | **داده‌های نمایشی** (latency، correlation، sentiment در UI) از منبع واقعی نمی‌آیند | نیاز به منابع داده ماکرو/مانیتورینگ واقعی. |

> بر اساس Goal Brief: «مورد باقی‌مانده فقط با دلیل روشن و تایید ذی‌نفع بسته شود» — موارد بالا دلیل روشن دارند و در گزارش مستند شده‌اند.
